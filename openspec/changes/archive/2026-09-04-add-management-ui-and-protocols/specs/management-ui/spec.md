## Purpose

提供可视化的 Web 管理界面，让用户通过浏览器配置 API/DB 连接、字段映射、同步任务，并查看执行日志，无需调用后端 API 即可完成全部操作。

## ADDED Requirements

### Requirement: 连接管理界面

系统 SHALL 提供连接管理页面，支持创建、查看、编辑、删除 API 和数据库连接，并可一键测试连接可用性。

#### Scenario: 创建 API 连接

- **WHEN** 用户在连接管理页面点击"新建连接"，填写名称、协议类型（REST/SOAP/GraphQL/WebSocket/gRPC）、Base URL、认证方式及凭证，点击保存
- **THEN** 系统创建连接记录并返回成功提示，连接列表中显示新创建的连接

#### Scenario: 创建数据库连接

- **WHEN** 用户选择连接类型为数据库，填写数据库类型（MySQL/Oracle/SQLite/PostgreSQL）、主机、端口、库名、用户名、密码，点击保存
- **THEN** 系统创建数据库连接记录，密码加密存储

#### Scenario: 测试连接

- **WHEN** 用户在连接列表中点击某连接的"测试"按钮
- **THEN** 系统尝试用该连接配置发起测试请求，返回连接成功或失败信息及错误详情

#### Scenario: 查看数据库表结构

- **WHEN** 用户点击数据库类型连接的"查看表结构"按钮
- **THEN** 系统展示该数据库下所有表及字段定义（名称、类型、是否可空）

### Requirement: 字段映射界面

系统 SHALL 提供可视化字段映射配置页面，支持源端到目标端的字段映射、类型转换配置，并支持预览转换结果。

#### Scenario: 配置字段映射

- **WHEN** 用户选择源连接和目标连接，添加映射规则（源字段→目标字段+转换类型），点击保存
- **THEN** 系统保存映射配置，映射列表中显示该映射

#### Scenario: 预览转换结果

- **WHEN** 用户在映射配置页面输入测试数据，点击"预览转换"
- **THEN** 系统按映射规则转换数据并展示转换后的结果，若有转换错误则显示错误详情

### Requirement: 任务管理界面

系统 SHALL 提供同步任务管理页面，支持创建、编辑、运行、暂停、恢复和删除同步任务。

#### Scenario: 创建同步任务

- **WHEN** 用户选择字段映射，配置同步模式（sync/async/auto）、调度方式（实时/定时Cron），点击保存
- **THEN** 系统创建任务记录，任务列表中显示该任务及状态

#### Scenario: 手动运行任务

- **WHEN** 用户点击任务的"运行"按钮
- **THEN** 系统立即触发该任务的同步操作，显示执行中状态，完成后显示成功或失败

#### Scenario: 暂停和恢复任务

- **WHEN** 用户点击运行中任务的"暂停"按钮
- **THEN** 任务状态变为已暂停，不再执行调度
- **WHEN** 用户点击已暂停任务的"恢复"按钮
- **THEN** 任务状态恢复为活跃，继续按调度执行

### Requirement: 执行日志界面

系统 SHALL 提供执行日志查看页面，支持按时间范围、任务、状态过滤，并查看错误详情。

#### Scenario: 查看日志列表

- **WHEN** 用户进入执行日志页面
- **THEN** 系统展示最近的执行日志列表（时间、任务名、动作、状态、耗时），支持分页

#### Scenario: 过滤日志

- **WHEN** 用户选择时间范围、指定任务、选择状态（成功/失败）进行过滤
- **THEN** 系统仅展示符合条件的日志记录

#### Scenario: 查看错误详情

- **WHEN** 用户点击某条失败日志的"详情"按钮
- **THEN** 系统展示该日志的请求数据、响应数据、错误信息、堆栈跟踪

### Requirement: 界面导航与布局

系统 SHALL 提供统一的导航布局，包含侧边栏菜单（连接管理、字段映射、任务管理、执行日志、监控看板）和顶部标题栏。

#### Scenario: 页面导航

- **WHEN** 用户点击侧边栏的任意菜单项
- **THEN** 系统切换到对应页面，侧边栏高亮当前菜单项
