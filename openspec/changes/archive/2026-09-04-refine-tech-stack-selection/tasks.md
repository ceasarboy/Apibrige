## 3. 同步传输处理器

- [x] 3.1 实现同步传输处理器（FastAPI 路由内：拉取源→写 data_buffer→转换→推送目标→更新状态）→ 验证: 单条数据同步处理 P99 <1秒，data_buffer 状态正确更新
- [x] 3.2 实现 fallback_to_async 开关（同步失败时按开关转异步）→ 验证: 开关关闭时失败直接返回，开关开启时转异步返回任务ID

## 4. 异步传输处理器

- [x] 4.1 实现异步提交入口（写 PostgreSQL data_buffer status=pending → 投递 RabbitMQ → 返回任务ID）→ 验证: 提交后立即返回任务ID，data_buffer 有 pending 记录，RabbitMQ 有消息
- [x] 4.2 实现 Celery Worker 消费逻辑（幂等检查→转换→限流检查→推送目标→更新 data_buffer 状态）→ 验证: Worker 消费后 data_buffer 状态变为 completed/failed，execution_logs 有完整记录
- [x] 4.3 实现投递失败补偿（扫描 pending 超时记录重新投递）→ 验证: 模拟 RabbitMQ 故障后恢复，pending 数据被补偿处理

## 5. 传输模式路由器
