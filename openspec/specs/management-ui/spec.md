# management-ui Specification

## Purpose
提供可视化的 Web 管理界面，让用户通过浏览器配置 API/DB 连接、字段映射、同步任务，并查看执行日志，无需调用后端 API 即可完成全部操作。
## Requirements
### Requirement: 连接管理界面

系统 SHALL 提供连接管理页面，支持创建、查看、编辑、删除 API 和数据库连接，并可一键测试连接可用性。

#### Scenario: 创建 API 连接

- **WHEN** 用户在连接管理页面点击"新建连接"，填写名称、协议类型（REST/SOAP/GraphQL/WebSocket/gRPC）、Base URL、认证方式及凭证，点击保存
- **THEN** 系统创建连接记录并返回成功提示，连接列表中显示新创建的连接

#### Scenario: 创建数据库连接

- **WHEN** 用户选择连接类型为数据库，填写数据库类型（MySQL/Oracle/SQLite/PostgreSQL）、主机、端口、库名、用户名、密码，点击保存
- **THEN** 系统创建数据库连接记录，密码加密存储

#### Scenario: 测试连接

- **WHEN** 用户在连接列表中点击某连接的"测试"按钮
- **THEN** 系统尝试用该连接配置发起测试请求，返回连接成功或失败信息及错误详情

#### Scenario: 查看数据库表结构

- **WHEN** 用户点击数据库类型连接的"查看表结构"按钮
- **THEN** 系统展示该数据库下所有表及字段定义（名称、类型、是否可空）

### Requirement: 字段映射界面

系统 SHALL 提供可视化字段映射配置页面，支持源端到目标端的字段映射、类型转换配置，并支持预览转换结果。

#### Scenario: 配置字段映射

- **WHEN** 用户选择源连接和目标连接，添加映射规则（源字段→目标字段+转换类型），点击保存
- **THEN** 系统保存映射配置，映射列表中显示该映射

#### Scenario: 预览转换结果

- **WHEN** 用户在映射配置页面输入测试数据，点击"预览转换"
- **THEN** 系统按映射规则转换数据并展示转换后的结果，若有转换错误则显示错误详情

### Requirement: 任务管理界面

系统 SHALL 提供同步任务管理页面，支持创建、编辑、运行、暂停、恢复和删除同步任务。

#### Scenario: 创建同步任务

- **WHEN** 用户选择字段映射，配置同步模式（sync/async/auto）、调度方式（实时/定时Cron），点击保存
- **THEN** 系统创建任务记录，任务列表中显示该任务及状态

#### Scenario: 手动运行任务

- **WHEN** 用户点击任务的"运行"按钮
- **THEN** 系统立即触发该任务的同步操作，显示执行中状态，完成后显示成功或失败

#### Scenario: 暂停和恢复任务

- **WHEN** 用户点击运行中任务的"暂停"按钮
- **THEN** 任务状态变为已暂停，不再执行调度
- **WHEN** 用户点击已暂停任务的"恢复"按钮
- **THEN** 任务状态恢复为活跃，继续按调度执行

### Requirement: 执行日志界面

系统 SHALL 提供执行日志查看页面，支持按时间范围、任务、状态过滤，并查看错误详情。

#### Scenario: 查看日志列表

- **WHEN** 用户进入执行日志页面
- **THEN** 系统展示最近的执行日志列表（时间、任务名、动作、状态、耗时），支持分页

#### Scenario: 过滤日志

- **WHEN** 用户选择时间范围、指定任务、选择状态（成功/失败）进行过滤
- **THEN** 系统仅展示符合条件的日志记录

#### Scenario: 查看错误详情

- **WHEN** 用户点击某条失败日志的"详情"按钮
- **THEN** 系统展示该日志的请求数据、响应数据、错误信息、堆栈跟踪

### Requirement: 界面导航与布局

系统 SHALL 提供统一的导航布局，包含侧边栏菜单（连接管理、字段映射、任务管理、执行日志、监控看板）和顶部标题栏。

#### Scenario: 页面导航

- **WHEN** 用户点击侧边栏的任意菜单项
- **THEN** 系统切换到对应页面，侧边栏高亮当前菜单项

### Requirement: 字段抽屉行内编辑字段定义

系统 SHALL 在连接「字段」抽屉中提供字段编辑能力：字段名称可修改，每个字段带「可读」「可写」两个勾选框（创建时默认均勾选）。

#### Scenario: 打开字段抽屉回显已保存定义

- **WHEN** 用户打开某连接的字段抽屉并拉取字段（DB 选表 / HAP 输入工作表 ID）
- **THEN** 已保存字段回显字典中的名称与读写勾选状态，未保存字段显示拉取值与默认双勾选，并带「未保存」标记

#### Scenario: 保存字段定义

- **WHEN** 用户修改字段名称或勾选状态（取消可读/可写）后点击「保存字段定义」
- **THEN** 系统按范围（table/worksheet_id）批量保存，成功后提示并在抽屉内刷新回显
- **AND** 默认新建连接字段初始为「既可读又可写」

### Requirement: 表单管理界面

系统 SHALL 提供独立的表单管理页面（与连接/映射/任务平级的菜单项），平铺展示全部已登记表单，支持按连接筛选与名称/备注搜索，支持从源端拉取表单清单与手动添加表单。

#### Scenario: 表单列表展示

- **WHEN** 用户打开表单管理页
- **THEN** 页面以表格平铺展示全部表单，列为：本地名称、原始名、form_key、所属连接、备注、来源（auto/manual 标签）、已建桥数、操作（编辑/删除）
- **AND** 已建桥数单元格悬停显示引用桥明细（桥名称、本表单方向 源/目标、对端连接名与对端表单标识）

#### Scenario: 按连接筛选与搜索

- **WHEN** 用户在顶部选择某连接（或保持全部）并输入搜索关键字
- **THEN** 列表按连接过滤并按本地名称/备注模糊匹配刷新

#### Scenario: 从源端拉取

- **WHEN** 用户点击"从源端拉取"（当前筛选了连接则针对该连接）
- **THEN** 系统调用 sync 端点拉取合并，完成后提示新增/刷新数量并刷新列表
- **AND** 拉取失败（如 HAP V3 不可用）时展示后端返回的错误原因

#### Scenario: 手动添加表单

- **WHEN** 用户点击"手动添加"，填写连接、form_key、显示名、备注并提交
- **THEN** 系统登记该表单（source=manual）并刷新列表；重复登记时提示冲突

#### Scenario: 编辑表单名称与备注

- **WHEN** 用户在某行点击"编辑"，修改显示名/备注并保存
- **THEN** 系统保存修改并刷新该行，原始名与来源不变

### Requirement: 映射创建页表单选择联动

系统 SHALL 在映射创建/编辑页中，当源或目标连接选中后，将表单选择改为从该连接的注册表下拉选择（显示 `本地名称（form_key）`），选中后自动填充对应的技术字段；同时保留手动输入方式兜底。

#### Scenario: 从注册表选择表单

- **WHEN** 用户选定源连接后，在表单下拉中选择某登记表单
- **THEN** 系统自动填充对应技术字段（HAP：mapping_config.protocol.worksheet_id 与 endpoint；DB：source_table/target_table）
- **AND** 后续"获取字段"按现行逻辑正常工作

#### Scenario: 手动输入兜底

- **WHEN** 注册表未登记目标表单，用户切换为"手动输入"并直接填写 worksheet_id/表名
- **THEN** 旧流程行为不变（拉字段、保存映射照常），无回归
