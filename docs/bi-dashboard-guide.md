# BI 大屏使用说明书

> 面向操作员：从零把「连接里的业务数据」变成一块可以投放的大屏。
> 相关：`docs/project-status.md`（进度与实测记录）、`skills/apibridge-cli/SKILL.md`（agent 配置剧本）、
> `docs/bi-dataease-study.md`（DataEase 范式研究）。
> 最后更新：2026-09-27

---

## 1. 概念（一分钟版）

- **BI 大屏展示的是「连接表单」里的业务数据**（明道云工作表 / 数据库表），不是平台自己的运行指标
  （那是「监控看板」的职责）。
- **指标定义**＝一张卡片的配方：数据源（哪个连接 + 哪张表）+ 图表类型 + 维度/度量 + 筛选 + 样式。
- **看板**＝一块 72×36 的自由画布，把若干指标定义**摆上去**（摆放即归属：没摆的不上屏）。
- **一个指标可以摆进多个看板**，定义只存一份；每个看板有**独立的投放地址**。

数据流：`连接/表单 → 指标定义（聚合每分钟刷新） → 看板摆放 → 投放页（大屏/浏览器全屏）`。

## 2. 快速上手（五步）

1. **建连接**：「连接管理」新建到你的数据源（明道云连接、SQLite/MySQL/PG/Oracle 数据库）。
2. **登记表单**：「表单注册表」把要展示的表/工作表登记进来（或点同步）。
3. **建指标**：「BI 大屏 → 指标定义」新建——选连接表单、选图表类型、选维度与度量，保存并启用。
4. **建看板**：「BI 大屏」顶部「新建看板」→ 自动进入布局编辑 → 从**卡片库**点选指标上屏 →
   拖动摆放、拖角调大小 →「完成」。
5. **投放**：点「投放模式」打开 `http://<主机>:3000/bi/screen?board=<看板key>`；
   按「全屏」或 F11 上大屏。到点自动刷新（1 分钟），无需人工干预。

## 3. 指标定义要点

| 项 | 说明 |
|---|---|
| 数据源 | 「连接表单」：先选连接、再选表单；字段列表带逻辑类型（维度/数值/时间） |
| 图表类型 | KPI 卡、折线/柱状（类别对比）、时间坐标系、饼图、散点、雷达、热力、3D 矩阵、桑基、关系、途径、树、漏斗、仪表盘、明细表 等 18 种 |
| 维度/度量 | 维度 ≤3；度量选聚合（sum/avg/count/min/max/p50/p95/**ratio 比率**）；散点恰 2 度量、关系族 ≥2 维度、仪表盘 ≤1 维度 |
| **计算字段** | 行级派生列：引用 `[字段中文名]` + 四则运算 + 函数（round/abs/ceil/floor/min/max/coalesce/substring/upper/lower/trim/concat/date_part）。如 `round([合格数] / [检验数] * 100, 1)`；可被维度/度量/筛选引用，派生列之间可互相引用（自动判环） |
| **聚合比（ratio）** | 先聚合分子分母再相除的整体比率：如 整体达成率 = Σ实际 ÷ Σ计划 ×100；分母为 0 显示 "—"。与"行级比率 + avg"是两种口径，按需选用 |
| **自定义分组** | 维度值归类：如 A线/B线→一车间、C线→二车间，未命中归"其他"（可留空保留原值）。定义页维度行「分组」按钮配置 |
| **展示修饰** | 占比（柱状/折线按系列总和换算 %）；累计（按 x 顺序累加，仅滚动源可用） |
| 筛选 | **类型感知**：数值=区间/大于小于，时间=起止，文本=等于/包含/属于……（定义级，生效于该卡片） |
| 样式 | KPI 卡底色/字体色（红/黄/绿语义：异常/临界/正常）；仪表盘量程 `gauge_min/gauge_max`；单位在样式里配 `unit`（如 `%`） |
| 明细表 | 直连表单原始行（不走聚合）；**大表逐行分析**：卡内工具条支持搜索/按列排序/升降序/翻页（单页 200 行，DB 源分页下推），页码与总行数在右上角；投放态**自动轮播滚动**，悬停暂停 |

## 3.5 分析工作台（先试再建卡）

管理页右上「**分析工作台**」按钮 → `/bi/analysis`。适合"还不知道该建什么指标"的探索期：
当场换维度/换指标看图，满意了再一键存成看板卡片。

| 操作 | 说明 |
|---|---|
| 选数据源 | 左上选连接 + 表单；右侧字段树按 **维度 / 指标（数值·时间）** 分组，可搜索 |
| 加字段 | **拖**字段到「维度」「指标」槽，或**直接点**字段（维度进维度槽、数值进指标槽）；维度最多 3 个 |
| 改口径 | 指标标签上点一下改聚合（求和/平均/最小/最大/计数/去重计数） |
| 换图 | 顶部图表类型（18 种）；Top N 控制分组条数，排序可按度量或维度升/降序 |
| 读标签 | 图上方的标签会说明这次查询是「**聚合下推**」（DB 源在源库算，快）还是「**内存聚合**」（HAP 源/计算字段等，标注源行数与截断） |
| 存卡片 | 「另存为看板卡片」→ 填卡片名与英文标识 → 可顺便选一个看板（自动找空位摆放）→ 保存后跳转可见 |

**注意**：分析过程**不写任何数据**（不落库、不建定义），只有点保存才生成卡片；
卡片与工作台用的是同一套口径，保存前后数值一致。

## 4. 看板与布局

- **切换/新建/重命名/删除**：都在 BI 大屏页顶部工具区。删除看板只清画布摆放，**指标定义不受影响**；
  「默认看板（default）」保留名不可删。
- **布局编辑**（点「布局编辑」）：
  - 拖动卡片到任意位置；拖角/边调整大小（72 列 × 36 行网格）；
  - **卡片库**（画布上方）列出所有启用但未上屏的指标，**点一下就上画布**；
  - 卡片右上角 × 把卡从**本看板**移出（定义仍在，可摆到其他看板）；
  - 所有改动**即改即存**到服务端。

## 5. 看板设置（右上「看板设置」）

### 投放显示
- **画布比例（基准分辨率）**：预设 1920×1080 / 1280×720 / 2560×720（带状屏）/ 4K，或自定义 W×H。
  同一版布局在任何基准下等比解释，换分辨率不用重排。
- **适配模式**（设备视口比例 ≠ 画布比例时才看得出差别）：

  | 设备场景 | 推荐模式 |
  |---|---|
  | 常规 16:9 显示器 / 1080p / 4K 大屏 | 等比缩放居中（默认） |
  | 超宽屏 / LED 条屏（画布偏方） | 宽度撑满·高度滚动 |
  | 竖屏 / 高屏 | 高度撑满·宽度滚动 |
  | 非标比例但要求铺满（接受轻微变形） | 拉伸填满 |

- **主题底色**：深色底（作战室/车间大屏）/ 白底（明亮环境、打印、投屏环境反光强时）；
  非全屏与全屏底色一致。

### 筛选元素
把某个维度（如「产线」）加成大屏顶部的下拉筛选器，选中值**联动所有含该维度的图表**。

> 设置改动保存后，**已经打开的投放页最多 30 秒自动跟随生效**，不用手动刷新。

## 5.5 分级投放（访问授权）

**场景**：同一块大屏投给不同人群，各自只看到自己该看的行与列。

1. 管理页右上「**访问授权**」→ 新建授权：填名称、选择可见看板（不选=全部看板）、
   行过滤（每行一个 `字段:值`，如 `line:A线`）、隐藏列（每行一个字段名）；
2. 保存后会**一次性显示令牌**（`bit_…`）——立刻复制保存，关掉就看不到了；
3. 用「复制投放链接」把 `…/bi/screen?board=<看板>&token=<令牌>` 发给对方浏览器打开：
   令牌会写入对方浏览器本地存储并**自动从地址栏移除**，之后刷新不再需要带参数；
4. 对方视角只能看到授权看板与授权卡片，数据已按行过滤、隐藏列不出现在任何接口响应里；
5. 令牌泄漏或人员变动：在授权列表点「轮换」（旧令牌立即失效）或「停用」。

**注意**：行过滤字段必须是卡片的**分组维度**，否则该卡片对这份授权不可见
（例如按 `line` 过滤时，"按日期分组"的趋势卡不会出现——它在行层面无法隔离）；
明细表与即席查询不受此限制（它们按行过滤）。

## 6. 投放页操作

- 地址：`/bi/screen?board=<看板key>`（不带参数＝默认看板）；每个看板一个地址，不同场合开不同链接。
- 右上角悬浮工具条（鼠标悬停可见）：刷新 / 指标定义 / 全屏 / 返回管理；**Esc 退出**。
- 页面按 1 分钟自动刷新数据。
- 明细表内容超出卡片时**自动向上轮播**（约每秒一行），到底停留后回顶循环；鼠标悬停暂停查看。

## 7. 常见问题

| 现象 | 处置 |
|---|---|
| 切换适配模式"没反应" | 设备比例与画布比例一致时四种模式数学等价（如 16:9 屏 + 1920×1080 画布）；把浏览器窗口拖成非 16:9 形状即可看到差别；或改用与设备匹配的画布比例 |
| 投放页改了设置不生效 | 最多等 30 秒自动跟随；仍不变按 Ctrl+F5 强刷 |
| KPI 数字/明细被裁 | 在布局编辑里把该卡**行数调大**（h 加 1~2 行）；竖向空间紧张时优先压缩趋势类卡片 |
| 白底主题下明细表样式不同 | 设计如此：深色底用深色表格，白底用浅色表格，滚动行为一致 |
| 卡片上没有数据 | 打开「指标定义」检查该指标是否启用、数据源连接是否可测通；聚合每分钟一轮，新建定义后等一轮或点刷新 |
| 想给不同客户/场合看不同内容 | 新建多个看板，各自摆放并各自投放（地址带 board 参数） |

## 8. 运维要点（管理员）

- **快照数据**：连接表单类指标每分钟形成"当前状态"快照，保留最近 60 个桶，自动清理，无需人工干预。
- **改指标筛选后不生效**：快照水位线已追平会跳过重算——需**同时清理该指标的桶与水位线**（缺一不可）后重跑聚合。
- **投放页无人值守**：建议浏览器全屏（F11）+ 系统不自动锁屏；断线恢复后页面会自动刷新数据。
- **凭证与安全**：连接凭证加密存储（`enc:` 前缀），任何对外输出（日志/响应/截图数据）均已脱敏；
  大屏数据来自真实连接，投放地址请按内部系统级别保护（`?board=` 参数不构成鉴权）。
- **改动后的标准回归顺序**（缺一步就会漏一类问题，2026-09-29 实测总结）：
  ① `python -m pytest tests/ -q`（后端行为）；
  ② `cd frontend && npx tsc --noEmit`（前端类型）；
  ③ 自审脚本（见下）——覆盖"脚本写到的那几页"；
  ④ **全页面巡检**：按路由清单逐页打开（含空态与被授权的受限视角）——脚本没覆盖的页面
     只能靠这一步（曾有一整页 500 是这样才发现的）；
  ⑤ **日志门禁**：触发一轮全量聚合/遍历主要接口后 `grep -iE "warning|error"` 后端日志——
     页面正常、测试全绿，也可能每轮都在刷告警（detail 卡空聚合就是这样被发现的）。
- **自审脚本**（改动后回归，随仓库保留）：
  - `scripts/production_bi_ui_check.py`（生产看板 17 项：KPI 对照/明细可见/自动轮播/控制台门禁）
  - `scripts/multi_board_ui_check.py`（多看板 14 项：新建/卡片库/投放独立地址/删除恢复）
  - `scripts/display_settings_ui_check.py`（显示设置 15 项：主题/适配模式/居中/轮询跟随）
  - `scripts/field_label_ui_check.py`（明细列别名 8 项）
  - `scripts/analysis_ui_check.py`（分析工作台 13 项：入口/字段树/拖拽与点击/切图/另存/数值一致）
  - `scripts/access_scope_ui_check.py`（访问授权 6 项：令牌注入与地址栏抹除/卡片级裁剪/
    响应不含越权值/控制台门禁）
  - `scripts/access_scope_verify.py`（访问授权真实数据：桶/明细/即席三路径 vs SQL 直查）
  这些脚本运行时会临时改显示设置或建临时看板，结束后自动还原/清理。
- **HAP 增量拉取（P4）**：行数超过阈值（默认 2 万）的明道云表单自动改走增量
  （按 `utime` 水位线只拉变化行 + 定期 600s 全量对账）。**删除的行最迟对账后才消失**——
  看板对删除敏感时，调高 `APIBRIDGE_HAP_INCREMENTAL_MIN_ROWS` 或设
  `APIBRIDGE_HAP_INCREMENTAL=0` 关闭增量并重启后端。当前模式可从
  `GET /bi/form-rows` 的 `snapshot.mode` 读到（增量实测报告：稳态拉取行数 2%）。
  真实端点验证脚本：`scripts/hap_incremental_verify.py`（需临时把阈值调 0 并重启后端）。
